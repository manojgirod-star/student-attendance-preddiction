# Student Attendance Prediction System

A simple and interactive web application that helps students calculate their attendance percentage and plan their classes effectively.

## Features
- Calculate attendance percentage
- Check missed classes
- Find the number of classes needed to reach the target attendance
- Estimate safe bunk classes
- Display attendance status and alerts

## Technologies Used
- HTML
- CSS
- JavaScript

## Live Demo
[Click here to use the website](https://menoozzzz-attendence.netlify.app)

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
